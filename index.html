SATP Registry — публичный API

Перечень организаций и физических лиц. Без ключа, без регистрации.

Статический API на GitHub Pages. Все эндпоинты — обычные JSON-файлы: curl https://x-cicada-ru.github.io/satp-registry/api/people/1.json

Эндпоинты

Метод и путьНазначение
GET /api/health.jsonПроверка доступности
GET /api/stats.jsonСтатистика реестра
GET /api/manifest.jsonОписание API
GET /api/people/index.jsonВсе физлица (сводки)
GET /api/people/letter/А.json … /Я.jsonСводки по букве раздела
GET /api/people/{id}.jsonКарточка физлица + полный текст
GET /api/orgs/index.jsonВсе организации (сводки)
GET /api/orgs/{id}.jsonКарточка организации + полный текст

Поля записи

ПолеОписание
idЧисловой идентификатор
nameПолное имя/название
aliasesПсевдонимы
Физлицоlast_name, first_name, middle_name, date_of_birth, year_of_birth, place_of_birth, letter
Организацияcountry, inn, ogrn, date
markedПризнак (true/false)
bodyПолный текст записи (только в карточках {id}.json)

Примеры (curl)

# Статистика реестра
curl https://x-cicada-ru.github.io/satp-registry/api/stats.json

# Все люди (сводки), 22 915 записей
curl https://x-cicada-ru.github.io/satp-registry/api/people/index.json

# Только буква «А»
curl https://x-cicada-ru.github.io/satp-registry/api/people/letter/А.json

# Карточка с полным текстом
curl https://x-cicada-ru.github.io/satp-registry/api/people/1.json

# «Поиск по параметрам» в браузере — ниже по этой странице

Поиск по параметрам (в браузере)

GitHub Pages не умеет фильтровать серверным запросом, поэтому полноценный поиск выполняется здесь — на вашей стороне: скачиваются сводки нужной буквы и фильтруются по тем же полям, что были бы в API-параметрах. Работает офлайн после первой загрузки.
